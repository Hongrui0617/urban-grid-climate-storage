# Raw Data

This directory is for local raw input data. Raw data files are not tracked by Git because of file size and data licensing considerations.

Expected local files:

```text
TEPCO_Load_2016_2022_hourly_with_units.csv
Tokyo_TempRH_2016_2022_hourly_wide_clean.csv
```

Expected source categories:

- TEPCO/OCCTO-type hourly electricity demand data for the Tokyo Electric Power Company service area.
- JMA-type hourly meteorological observations for Tokyo, including temperature and relative humidity.
